# WoW: Forever 레벨링 프로필 샘플

| 파일 | 대상 |
|---|---|
| `흑마_고통.json` | 고통 흑마법사 |
| `전사_방어_20.json` | 20레벨 방어 전사 (솔로·파티 탱) |
| `도적_전투_16.json` | 16레벨 전투 도적 (검/둔기) |
| `드루이드_곰_17.json` | 17레벨 곰 드루이드 (솔로·파티 탱) |

## 사용법

1. 쓰려는 파일을 `profiles/`로 복사한다.
2. 앱에서 프로필을 열고, 위치가 (0,0)인 상태(`상황_*`, `몹수_1`, `내_HP_*`, `분노_*`, `READY_*` 등)를 게임 화면의 조건 표시 칸에 맞춰 하나씩 다시 캡처한다. 캡처 전에는 실행되지 않는다.
3. 키는 `1~9`, `0`, `-`, `=` 기준이다. 게임 액션바에 맞게 바꾼다.

## 전제

- `몹수_1`은 켜짐이 1마리, 꺼짐이 2마리 이상이다.
- `READY_*`는 재사용 대기·자원·사거리가 모두 충족된 사용 가능 표시를 뜻한다.
- 분노 기준값은 클래식 비용(천둥벼락 20, 방어구 가르기·영웅의 일격 15, 방패 막기·방패 가격·사기의 외침 10, 복수 5)을 전제로 한다.
- 기본 꺼짐 동작: `단일_사기의외침`(전사), `단일_위협의포효`(드루이드). 상황에 따라 직접 켠다.
- `도적_전투_16`의 `이탈_대상해제`는 키가 비어 있다. `/cleartarget` 매크로 키를 넣는다.
