| 5 | 이벤트 편집기가 게임 화면을 크게 가림 | 측정값: 창 1004×453, 캡처 미리보기는 100×100 두 개(면적 약 4%). 크기를 차지하는 것은 탭 레일(191px), 입력칸, 가장 큰 탭 기준으로 고정한 높이다. |

| 현재 | 목표 | 항상 위 | 모달 |
| --- | --- | --- | --- |
| 메인 창 | **실행 창** | – | – |

### 3.1 실행 창

```
┌ Keystroke Simulator ────────────────── ⚙ ┐
│ 대상    [WoW.exe (1234)         ▾] ⟳     │
│ 실행    [BM_야수                ▾]       │  ← 프로필 + 저장된 실행 세트
│ 수정키  [기본                   ▾]       │  ← 독립 선택 유지
│ ● 준비됨 · 규칙 13 · 신호 13             │  ← 상태 한 줄
│                           [ ▶ 시작  ` ]  │
└──────────────────────────────────────────┘
```

- "실행" 콤보에 프로필과 저장된 실행 세트를 구분선으로 함께 보여준다. 프로필을 고르면 단일 실행이다. 기존 가상 항목 `__current__`의 역할을 대신한다.
- 프로필·실행 세트의 편집·복사·삭제·정렬은 작업 공간으로 옮긴다. 수정키 세트의 편집·복사·삭제는 ⚙ 메뉴로 옮긴다.
- 상태는 한 줄로 표시하고, 막혔을 때만 해결 버튼 하나를 보여준다.
- 빠른 이벤트, 설정, 로그 삭제는 ⚙ 메뉴(macOS에서는 메뉴바에도)로 옮긴다.
- 메인 창에서 Esc를 눌러 앱이 종료되는 동작을 없앤다.

### 3.2 작업 공간

```
┌ 프로필 ─────┬ BM_야수 ──────────────────────┬ 상세 ──────────────┐
│ ★ BM_야수   │ [목록 | 그래프]  🔎          ＋ │ 05 격노             │
│   전사_방어 │ ▾ 신호 (13)                    │ 키 [5]              │
│   Quick     │   날사2   (812,440) ■          │ 조건                 │
│ ── 실행 세트 │ ▾ 규칙 · 그룹 야수 (13)         │  격노준비  [켜짐 ▾]  │
│   레이드    │ ⋮⋮ 날사_캡        3  날사2      │  ＋ 조건 추가        │
│  ＋ 새로…   │ ⋮⋮ 격노           5  격노준비…  │ ▸ 고급  ▸ 화면 [캡처]│
└─────────────┴───────────────────────────────┴────────────────────┘
```

- **왼쪽 사이드바:** 프로필과 실행 세트 목록. 복사·삭제·이름 변경·즐겨찾기는 우클릭으로 한다. Quick은 삭제할 수 없다.
- **가운데 목록:** 신호(`execute_action=False`)와 규칙(`execute_action=True`) 두 섹션으로 나눈다. 규칙은 그룹별로 묶는다.
  - 목록 순서가 곧 우선순위다. 드래그하면 저장할 때 그룹 안의 순서값을 `priority`에 쓴다.
  - 행에는 이름, 키, 조건 요약만 둔다. 편집·복사·삭제는 호버, 키보드, 우클릭으로 한다.
  - 규칙이면서 다른 이벤트의 조건으로 참조되는 이벤트는 규칙 섹션에 두고 "참조됨" 배지를 붙인다.
- **오른쪽 상세 패널:** 행을 선택하면 바로 편집한다. ↑/↓로 이동한다. 조건은 "＋ 조건 추가 → 신호 선택 → 켜짐/꺼짐" 목록으로 입력한다. 타이밍·반전·영역 모드는 "▸ 고급"에 접는다. 화면 트리거는 "캡처" 버튼으로 HUD를 연다.
- 그래프는 목록 자리의 탭으로 둔다. 저장은 자동 저장 하나로 통일한다.
- 모달이 아니므로 게임 창과 번갈아 쓸 수 있다. 실행 중 편집 정책은 4.1절을 따른다.

### 3.3 캡처 HUD

```
┌ 날사2 (클릭해 이름 편집) ── ✕ ┐   ← 폭 약 260~300px, 항상 위
│ [캡처본 1:1]  [돋보기 8×]      │
│ ■ 255,0,255  (812, 440)        │
│ ALT 이동 · CTRL 고정 · 클릭 지정│
│ [다시 캡처]           [적용 ↵] │
└────────────────────────────────┘
```

- **미리보기:** 1:1로 보여주고 최대 200px로 제한한다. 정밀하게 고를 때는 돋보기(8×)를 쓴다.
- **화면 전환:** 한 칸에서 캡처본과 실시간 화면을 전환한다. ALT를 누르고 있는 동안만 실시간 화면이다.
- **정보 표시:** 좌표와 색은 한 줄로 보여준다. X1/Y1/X2/Y2 입력칸과 캡처 크기 스핀박스는 "▸ 고급"에 접는다.
- **자동 이동:** HUD가 캡처 박스와 겹치면 반대편 모서리로 스스로 이동한다. 겹침 경고를 대체한다.
- **단축키 예외:** 텍스트 입력칸에 포커스가 있으면 CTRL 캡처를 무시한다. 그 밖의 ALT/CTRL 전역 감지는 유지한다. 게임 위로 마우스를 옮기는 흐름을 지키기 위해서다.
- **모드**
  - 단일 모드: 작업 공간이나 편집기에서 연다. "적용"하면 해당 이벤트의 화면 정보를 갱신한다.
  - 연속 모드: 빠른 이벤트. 적용할 때마다 Quick 프로필에 추가하고 다음 캡처로 넘어간다.
- **캡처 영역 테두리(2단계):** 캡처 박스 바깥쪽 2px 테두리를 게임 위에 그린다. 편집 중에만 표시하고 실행 중에는 표시하지 않는다.

### 3.4 용어

| 현재 | 목표 |
| --- | --- |
| 조건 전용 이벤트, `execute_action=False` | 신호 |
| 실행 이벤트, 화면 없는 입력 | 규칙 (화면 트리거는 선택 사항) |
| 그룹 + 우선순위(0이 최우선) | 그룹 안에서 목록 위쪽이 먼저 |
| 토글 세트, 토글 트리거 | 단축키로 켜고 끄기 |
| 반전 매칭 | 색이 다를 때 |
| 주의 필요 | 키 없음 |
| ModKeys, 수정키, Modifier Keys | 수정키 |
| Workstation | 삭제 |

UI 문자열은 호출부에서 `txt(en, ko)`로 두 언어를 함께 바꾼다.

## 4. 불변조건과 정책

- `profiles/*.json` 저장 계약과 processor의 조건·그룹·runtime toggle 의미를 바꾸지 않는다. 신호/규칙은 표시 개념이며 `execute_action`으로 판정한다.
- **우선순위 이관**
  - 기존 프로필은 그룹 안에서 `(priority, name)` 순으로 표시한다. 이 순서는 현재 실행 순서와 같다.
  - 드래그로 순서를 바꾸기 전에는 `priority`를 다시 쓰지 않는다.
  - 순서를 바꾸면 그룹 안에서 0부터 순서값을 쓴다.
  - 그룹이 없는 규칙은 모두 실행되므로 순서가 실행에 영향을 주지 않는다. 이 점을 UI에 표시한다.
- Quick 프로필은 삭제할 수 없고, 연속 캡처의 저장 대상이다.
- 수정키 세트 선택은 실행 세트·프로필과 독립이다.
- 캡처 HUD는 topmost를 유지한다.
- Tkinter 위젯 변경은 메인 스레드에서 한다. 색·폰트·간격은 `app/ui/theme.py` 토큰을 쓴다.
- canonical 경로는 `app/*`뿐이다. 제거된 루트 레거시 모듈을 다시 만들지 않는다.

### 4.1 실행 중 편집 정책 (3단계부터)

- 작업 공간이 모달이 아니게 되면 실행 중에도 편집할 수 있다.
- 실행은 시작 시점에 합성한 스냅샷을 쓴다.
- 편집 내용은 다음 시작부터 반영하고, 실행 중에는 작업 공간에 "다음 시작부터 반영" 안내를 표시한다.
- 실행 중에는 프로필 삭제와 이름 변경을 막는다.

### 1단계. 캡처 HUD

편집기와 빠른 이벤트의 캡처 부분을 공용 HUD로 만든다. 백로그 H-01~H-08.

- 새 모듈 `app/ui/capture_hud.py`를 만든다. 미리보기, 오버레이, 좌표 선택, 돋보기, 자동 이동을 모은다. `CaptureSession`을 그대로 쓴다.
- **이벤트 편집기**
  - 기본 탭의 캡처 영역을 "화면" 요약(썸네일, 좌표, 색)과 "캡처" 버튼으로 바꾼다.
  - 편집기는 topmost를 해제한다. HUD가 열려 있는 동안은 grab을 HUD로 넘긴다.
- **빠른 이벤트**
  - 연속 모드 HUD로 대체한다.
  - 지금처럼 CTRL을 두 번 누르는 흐름(첫 번째는 고정, 두 번째는 저장)을 "적용"으로 명확히 한다. 두 번째 CTRL이 새 프레임을 다시 캡처하는 문제는 저장 시점의 이미지를 그대로 쓰도록 고친다.
- 편집기와 빠른 이벤트에 중복된 미리보기·좌표 코드를 HUD로 모으고, 원래 위치의 코드는 삭제한다.

### 2단계. 캡처 영역 테두리

백로그 O-01~O-03.

- 2px 폭의 테두리 창 4개(`overrideredirect`, topmost)를 캡처 박스 바깥쪽에 배치하고, ALT 이동을 따라가게 한다.
- HUD가 열려 있을 때만 표시한다. 실행 중에는 만들지 않는다.
- 테두리가 캡처 이미지에 섞이지 않는지 macOS(SCStream)와 Windows(mss)에서 확인한다.
- 테두리 사용 경험을 확인한 뒤, 실시간 미리보기 제거 여부를 결정해 백로그에 기록한다(O-03).

### 검증

- 테두리 좌표 계산 단위 테스트
- E2E: macOS·Windows 각각 테두리 표시, 캡처본 오염 없음, 화면 가장자리 동작

### 3단계. 작업 공간

프로필 관리자를 작업 공간으로 재구성한다. 가장 규모가 크므로 3a~3c로 나눠 커밋한다. 백로그 W-01~W-14.

- **3a. 목록**
  - 신호/규칙 섹션, 그룹 묶음, 행 간소화, 드래그 순서와 `priority` 기록.
  - 정렬 창(`sort_events.py`)과 메인 창의 정렬 버튼을 제거한다. 프로필 창의 "↕ 정렬" 메뉴는 "이름순으로 한 번 정렬"하는 동작으로 남기되, 되돌리기를 지원한다.
- **3b. 상세 패널 편집**
  - 인스펙터가 편집기의 이름·키·조건·그룹·고급 항목을 흡수한다. 모달 편집기(`event_editor.py`)는 제거하거나, 캡처 HUD 호출부만 남긴다.
  - 조건 추가 목록 UI를 넣는다.
  - 새 이벤트 추가: "＋ 신호"는 HUD를 열고, "＋ 규칙"은 상세 패널에서 바로 시작한다.
- **3c. 사이드바**
  - 프로필·실행 세트 목록과 관리 동작을 넣는다. 실행 세트 편집 대화상자를 흡수한다.
  - 가져오기는 "다른 프로필로 복사"로 대체한다.
  - 그래프는 탭으로 옮긴다.
  - 작업 공간을 모달이 아닌 창으로 바꾸고, 4.1절 정책을 적용한다.

### 4단계. 실행 창

메인 창을 실행 전용으로 축소한다. 백로그 M-01~M-06.

- "실행" 콤보에 프로필과 저장된 실행 세트를 합친다. 기존 `app_state.json`의 선택값(프로필, 실행 세트 id)을 새 콤보 선택으로 이관한다.
- 수정키 콤보는 유지하고, 관리 버튼은 ⚙ 메뉴로 옮긴다.
- 상태 카드를 한 줄로 줄이고, 막혔을 때만 해결 버튼을 보여준다.
- 도구 카드를 ⚙ 메뉴로 옮기고, Esc 종료를 없앤다.
