# 전사 — KeySim 로테이션 규칙

**작성일:** 2026-08-14
**상위 문서:** [`midnight-rotation-handoff.md`](midnight-rotation-handoff.md)
**근거:** `simulationcraft/simc` `midnight` 라이브 APL (2026-08-14 fetch) + Icy Veins 12.1
**전제:** AC(JustAC / Shinkili)를 필러로 두고, 이산 신호만 예외로 얹는다. 장신구·물약·종족기·차단·큰 생존 쿨은 핸드오프 §4대로 **수동**.

12.1 추천 영웅 특성: 분노·무기 **학살자**, 방어 단타 **거신** / 광역 **산의 영주**.

---

## A. 분노

### A.1 기본 진단

AC는 `격노 꺼짐 → 광란`까지는 있다. **무모한 희생·화신도 AC 본문에 있다** — `recklessness,if=cooldown.slam.ready` / `avatar,if=cooldown.slam.ready` (assisted_combat 4·5행). `actions.cooldowns`에도 중복 등재돼 있을 뿐, "어시스트가 안 고르는 줄"이 아니다.
default `actions.slayer` 갭은 **격노 잔여 <1글쿨 패킹**, 무모한 희생 창 안 재배치, 분노 100 홀드다.

### A.2 확정 규칙 (학살자)

```
1. 격노 버프 꺼짐                         → 광란
2. 급살                                   → 마무리
3. 난도질                                 → 분쇄의 일격(창 안) / 분노의 강타
4. 소용돌이 / 광역                         → AC 추천 추종 (적 수는 AC)
5. 이하 AC 추천 추종
```

| 규칙 | 근거 | 비고 |
| --- | --- | --- |
| 1 | `slayer:48` `rampage,if=buff.enrage.remains<gcd` | 잔여 <1글쿨은 관측이 어려움. **꺼짐**만 확정.<br>⚠️ **AC에 이미 있다** (`rampage,if=buff.enrage.down`) → 예외 레이어에 둘 필요가 없다 |
| 2 | `slayer:61` `execute,if=buff.sudden_death.up`<br>(`slayer:52`는 무희 중 한정으로 더 위) | 2중첩까지 쌓인다는 서술은 fury APL에 근거가 없다(`stack` 조건은 **무기**에만 존재) — 미확인 |
| 3 | `thane:90` `crushing_blow,if=buff.hack_and_slash.up`<br>`thane:95` `raging_blow,if=buff.hack_and_slash.up` | ⚠️ **산의 영주(`actions.thane`) 줄이다.** 이 절 제목은 (학살자)인데 근거가 다른 영웅 트리다.<br>`slayer:54`는 조건 없는 `crushing_blow`, `slayer:53`은 `rampage,if=buff.recklessness.up&!buff.hack_and_slash.up` 로 **부정 조건**이다 |
| 4 | AC가 소용돌이를 고름 | 키심에 적 수 조건을 넣지 않는다 |

### A.3 남은 추가

| 규칙 | 근거 |
| --- | --- |
| 무모한 희생 켜짐 AND 칼날폭풍 준비 → 칼날폭풍 | `bladestorm, if=buff.recklessness.up` — 직전 광란은 이상일 뿐 강제 아님 |
| 산의 영주: 천둥 작렬 2중첩 → 천둥 작렬 | `thunder_blast, if=buff.thunder_blast.stack=2` |
| 무모한 희생·화신 준비 | 표시 또는 수동. AC 풀에 없을 수 있음 |

### A.4 구현 불가

분노 100 이상 광란, 격노 잔여 <1글쿨, 창 안 스킬 미세 재배치, 학살자/산의 영주 자동 전환.

### A.5 §4 편차

무모한 희생·화신은 1분급 큰 쿨이다. 키심 예외 레이어에 **넣지 않는다.**

다만 AC 본문 4·5행이 이 둘을 추천하므로, **F 슬롯을 그대로 추종하면 이미 자동 입력된다.** "AC가 안 고르면 넣지 않는다"가 아니라 **"필러에서 빼지 않으면 자동된다"** 가 사실이다. 핸드오프 §4를 지키려면 필러 매핑에서 제외해야 한다. (BM 문서 §8과 동일 사안)

## B. 무기

### B.1 기본 진단

AC는 짧은 평탄 리스트(분쇄 없으면 유지 → 휩쓸기 3+ → 파괴자 → 거강 → 필사 → 마무리 → 제압 → 격돌).
default는 거신/학살자 × 단타/광역/처형 **6리스트**. 색으로 전부 못 따라간다. 목표는 **AC + 창/캡/프록**.

### B.2 확정 규칙 (학살자)

```
1. 제압 2충전                              → 제압
2. 기회주의자 2중첩                        → 제압
3. 급살 2중첩                              → 마무리
4. 거강 디버프 on AND 칼날폭풍 준비        → 칼날폭풍
5. 휩쓸기                                  → AC 추천 추종 (적 수는 AC)
6. 이하 AC 추천 추종
```

| 규칙 | 근거 | 비고 |
| --- | --- | --- |
| 1 | `overpower, if=talent.dreadnaught&charges=2` (광역) | 캡 방지. 단타도 동일하게 둠 |
| 2 | `overpower, if=buff.opportunist.stack=2` | |
| 3 | `execute, if=buff.sudden_death.stack=2` | 1중첩은 AC에 맡김 |
| 4 | `bladestorm, if=debuff.colossus_smash.up\|buff.avatar.up` | 거강 **안**에 쓴다 |
| 5 | AC가 휩쓸기를 고름 | 키심에 적 수 조건을 넣지 않는다 |

거신이면 규칙 4를 **거강 디버프 AND 철거 준비 → 철거**로 바꾼다 (`demolish, if=...colossus_smash.up`).

### B.3 남은 추가

| 규칙 | 근거 |
| --- | --- |
| 거강 직전 파괴자 | `ravager, if=cooldown.colossus_smash.remains<=gcd` |
| 전쟁의 지배자 → 영웅의 일격 | AC에도 있음. 보험 |
| 부수 피해 3 → 회전베기 | 중첩 관측 가능할 때만 |

### B.4 구현 불가

분쇄 잔여 수식, 거인의 힘/집행자의 정밀 중첩 운용, 처형(20/35%) 리스트 전환, 날사식 멀티닷.

### B.5 §4 편차

거인의 강타는 짧은 로테이션 창이다. AC가 추천하면 따라가도 된다. 화신·파괴자는 거강과 맞출지 **수동**이 안전하다.

## C. 방어

핸드오프는 탱 본업을 제외했지만, **공격 필러 + 이산 프록**만 적는다. 방패의 벽·최후의 저항 등 큰 생존은 수동.

### C.1 기본 진단

AC: 전투의 외침 → **화신** → 파괴자 → 철거 → 천둥 작렬(프록) → 방패 밀쳐내기 → 천둥벼락 → 복수(4+) → **방패 돌진** → 마무리 → 복수 → 파괴의 일격.
default는 고통 감내 분노 수식, 방패 막기 `remains<=10`, 영웅 트리 분기가 많다. 수식은 포기한다.

### C.2 확정 규칙

```
1. 천둥 작렬 2중첩                         → 천둥 작렬
2. 복수 프록(무료)                         → 복수
3. 방진 없음 AND 천둥벼락 준비             → 천둥벼락 (거신 단타)
4. 이하 AC 추천 추종 (방패 밀쳐내기가 뼈대)
```

| 규칙 | 근거 | 비고 |
| --- | --- | --- |
| 1 | `31행` `thunder_blast,if=talent.booming_voice&buff.thunder_blast.stack=2&talent.snap_induction`<br>`35행` `thunder_blast,if=spell_targets.thunder_blast>=2&buff.thunder_blast.stack=2` | ⚠️ **조건 없는 2중첩 줄은 없다.** 둘 다 특성 또는 대상 수 조건이 함께 붙는다.<br>둘 다 **최상위 공통 블록**이다(산의 영주 전용 아님). `thane_st:75`·`thane_aoe:67`은 오히려 **무조건** `thunder_blast` |
| 2 | `colossus_st:57` · `colossus_aoe:45` · `thane_st:78` · `thane_aoe:70` `revenge,if=buff.revenge.up` | 네 리스트 모두에 존재. 12.1 세트 관련 서술은 APL에 근거가 없다 — 별도 출처 필요 |
| 3 | `colossus_st:55` `thunder_clap,if=!buff.phalanx.up` (같은 줄이 `65행`에도) | ⚠️ **`colossus_st` 리스트의 첫 줄이다** — 복수보다 위. 아래 키심 표의 P30(필러 밑)은 이 순서와 어긋난다.<br>`colossus_st` 전용이므로 산의 영주에는 적용하지 말 것 |

### C.3 남은 추가

| 규칙 | 근거 |
| --- | --- |
| 거인의 힘 3+ AND 철거 → 철거 | `demolish, if=buff.colossal_might.stack>=3` |
| 방패 막기 버프 ≤10초 → 방패 막기 | `shield_block, if=buff.shield_block.remains<=10` — 유지기. 큰 쿨 아님 |
| 힘의 폭발 → 방패 밀쳐내기 연속 | 프록이 아이콘이면 |

고통 감내는 분노가 꽉 찰 때 덤프. 숫자라 키심 확정에서 뺀다. 수동 또는 관측 가능할 때만.

### C.4 구현 불가

분노 deficit 수식, 방패 막기 스윙 타이밍, 화신 중 천둥벼락 격글쿨 교차의 완전 재현.

### C.5 §4 편차

화신·사기의 외침·파괴자·방패 돌진은 AC가 일부 빼거나 SimC가 덧붙인다. **준비 표시 또는 수동.** 방패 막기는 로테이션 유지기여서 예외에 넣어도 된다.

## 키심 이벤트·조건

`감_` = 감지(실행 끔). `색_` = Shinkili 추천 색. `priority`는 작을수록 먼저. **적 수는 AC.** 무희·화신·방패의 벽은 입력 안 함.

| --- | --- |
| `감_격노꺼짐` | 격노 버프 없음 |
| `감_급살` | 급살 |
| `감_난도질` | 난도질 |

| P | 이벤트 | 키 | 활성 필요 |
